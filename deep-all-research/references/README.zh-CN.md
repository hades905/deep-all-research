# Deep All Research 技能中文说明

这个技能用于把“全网搜集某个主题的信息”变成一套可复用流程。你以后只需要说出要研究的对象，例如：

- “帮我全网搜集 XX 技术，整理到 Obsidian。”
- “深入研究某家公司最近的新战略。”
- “整理某个政策、产品、人物、事件、争议的资料库。”

Codex 使用这个技能后，会自动完成：

1. 找到合适的 Obsidian 仓库位置。
2. 创建主题资料夹。
3. 全网搜集官方资料、论文、媒体报道、评论、争议和影响。
4. 下载适合本地保存的原始文件，例如 PDF、PPT、DOC、表格等。
5. 不把普通网页保存成本地 HTML，而是在文档里直接放网页链接。
6. 生成多篇 Markdown 文档，而不是一篇大杂烩。
7. 区分事实、来源说法、外部评价、争议、误读、影响和待验证问题。
8. 最后检查文件、链接、附件和占位内容。

默认输出结构包括：

- `00-索引与总览.md`
- `01-这是什么.md`
- `02-技术或领域拆解.md`
- `03-原始资料与时间线.md`
- `04-外部评价、争议与误读.md`
- `05-影响地图.md`
- `06-关键判断与待验证问题.md`
- `07-资料来源清单与可信度.md`

核心原则：

- 网页只放在线链接，不保存 HTML。
- 原始 PDF、PPT、报告、论文等才下载保存。
- 官方资料优先，评论资料分层看待。
- 不把宣传、市场情绪、个人评论当作已验证事实。
- 交付前必须自检。
